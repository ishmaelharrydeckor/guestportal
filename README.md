# Guest Portal & Event Check-In System

A digital check-in portal and guest management application designed for smooth attendee registration, event badge verification, and guest experience management.

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router, TypeScript)
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

---

## ✨ Features

- **Guest Registration & Verification**: Client-side validated registration forms with QR code / badge verification.
- **Administrative Dashboard**: Real-time overview of checked-in guests, pending invitations, and attendance statistics.
- **Mobile First**: Built for fast check-in operations on mobile phones and tablets at venue doors.

---

## 📦 Getting Started

```bash
npm install
npm run dev
```
